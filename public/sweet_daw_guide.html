AIMIXから簡易マスタリングへの流れ

Reference付きの複数stemを仕上げる場合は、次の順番をSweet DAWの標準フローとして使用します。AIMIXでバランスを作り、Spatialで定位を整理してから、最後にDark GlossとLight Masterを適用します。

標準フロー: Reference＋stem読み込み → AIMIX Standard → FIX → Run Reference Finish → Spatial Auto → Dark Gloss → Light Master → Render Processed Master → Processed WAV書き出し
  1. Files または Arrange でstemとReferenceを読み込みます。 Suno由来のstemは数字順に並びます。数字で始まらない完成WAVはReferenceとして扱い、解析の目標に使用します。
  2. Arrangeでトラック順、波形、Roleを確認します。 スマホではMove LockをONのままにし、clipを編集する時だけ解除します。Project BPMもこの段階で確認します。
  3. AIMIXタブで「AIMIX Standard」を実行します。 Before / Afterを聴き、音量だけでなくVocalの輪郭、低域、こもりを確認します。Afterが良い場合は「FIXする」でプロジェクトへ確定します。
  4. Referenceが解析済みなら「Run Reference Finish」を実行します。 Referenceの音量、密度、帯域を目標としてstem mixを安全範囲で整えます。Reference音声そのものをmixへ加える処理ではありません。
  5. Spatialタブで「Spatial Auto」を実行します。 Vocal、Bass、Drumsを中央に保護し、Support、Synth、Guitar、FXを必要な範囲だけ左右へ整理します。品質条件を満たさない場合は自動的にAIMIX後の状態へ戻ります。
  6. MasteringタブのAIMIX Glowで「Dark Gloss」を選びます。 Vocal連動の控えめな艶と明瞭感を加えます。明るさを強く足すプリセットではなく、刺さりやAI由来のざらつきを避ける仕上げとして使います。
  7. 簡易マスタリングは「Light Master」を選びます。 通常はTarget LoudnessとTrue Peakの初期設定を維持します。Reference Catch-UpやLoud Releaseは、標準結果を確認した後に必要な場合だけ使用します。
  8. 「Render Processed Master」を押して仕上がりを準備します。 処理後はOriginal / ProcessedでA/Bし、Vocal、低域、艶、音圧に不自然さがないか確認します。
  9. 同じ場所の「Export Processed WAV」を押します。 未レンダー時は「Polish & Export Processed WAV」と表示され、レンダーと書き出しを一度に行います。iPhoneでは進捗画面を閉じず、そのまま完了まで待ちます。
  10. 必要に応じてFilesからプロジェクトや素材も保存します。 .swtdは音声素材を含むプロジェクトです。Filesの「WAV」はAIMIX、Spatial、Plug-inを含むプロジェクトミックスを書き出し、Masteringの一時的なProcessed音声を確実に含める場合は「Export Processed WAV」を使います。
大事な考え方: Reference は目標の分析に使います。通常の書き出し WAV に Reference 音声そのものは混ざりません。
書き出し名: Referenceがまだまだ.wavの場合、初回はまだまだ_sw_master.wav、次回はまだまだ_sw_master_02.wavとして保存されます。
標準フローへ処理を足しすぎない: High boost、Stereo widen、Limiter drive、Exciter、強いReverbを重ねると、AI音源のざらつきやこもりが目立つ場合があります。まずDark Gloss＋Light Masterで確認してください。

Sweet DAWのMix Philosophy

Sweet DAWは、音量を先に上げるのではなく、stemの役割、帯域、定位を整理してから仕上げるためのWeb DAWです。AIMIXは強い加工を自動で重ねる機能ではなく、Before / Afterを確認しながら必要な補正だけをFIXする提案型の流れを基本にしています。

Low-End
20〜60Hzを無理に増やさず、80〜120Hzと倍音でスマホでも聴こえる低域へ翻訳します。Bass / Kick / Subは中央を守ります。
Vocal
Airだけで明るくせず、300〜600Hzのこもり、3〜5kHzの輪郭、6〜9kHzの刺さりを順番に確認します。Lead Vocalは基本的に中央です。
Stage
Stereo Widenerで全体を広げるのではなく、Guitar / Synth / FXなどのsupport stemを小さく左右へ配置します。低域はwide pathへ入れません。
Mastering
Limiterで押し切らず、密度、コントラスト、True Peak安全性を見ながら最後に整えます。Denseは音圧優先ではなく、軽い密度補正として扱います。
Safeでは、自動のParallel Comp、Reverb、Widener、Bass Translatorを挿しません。まずBalancedでA/Bし、必要な場合だけDenseや個別プラグインを使うのが標準です。

BPM Lock

BPM Lock は、一定BPMのstemを Project BPM のグリッドへ軽く寄せるための補助/上級機能です。元ファイルを直接上書きせず、補正済みの新しい audio asset と clip を追加します。

いつ使うか
曲全体がほぼ一定BPMで、stem 同士は合っているが Arrange の beat grid から少しずれている時だけ使います。万能な拍合わせ機能ではありません。
基本モード
通常は Tight を選びます。音の自然さとグリッド追従のバランスが良く、Suno stemの標準作業に向いています。
Reference
数字で始まらない完成WAVがある場合は、解析用Referenceとして使えます。Reference音声そのものは、通常のmix書き出しへ混ぜません。
Undoしやすい設計
BPM Lock後は元clipを残しつつ、補正済みclipを新規トラックとして扱います。不要なら補正済みトラックを削除できます。

表示項目の意味

項目意味目安
Target BPMProject BPMとして使うテンポです。Referenceやstem解析から近い値を選び、必要なら手動で調整します。
Ready stem countBPM Lock対象として準備できているstem数です。0の場合は、先にstemを読み込んでください。
Mode補正の強さです。Looseは自然、Tightは標準、Hardはドラムが明確な素材向けです。
Confidence解析結果の信頼度です。低い場合は無理に補正せず、Project BPMやReferenceを確認してください。
Max Warpどの程度タイミング補正を許可するかです。大きくしすぎると音質が崩れるため、必要最小限にします。
Rendered / Skipped実際に補正済みassetを作った数と、対象外にした数です。Skippedが多い場合は、短すぎる素材やReference扱いのファイルが混ざっていないか確認します。
標準導線: stem読み込み → 自動設定されたProject BPM確認 → Arrangeで波形確認 → AIMIX Standard / Reference Finish → Spatial Auto → Dark Gloss → Light Master → Processed WAV書き出しが基本です。BPM Lockは一定BPMの素材で必要な時だけ開いてください。
注意: BPM Lockは長尺stem全体を高品質にtime-stretchする万能機能ではありません。Reference自体の揺れが大きい場合は、意図的なテンポ変化の可能性があるため自動レンダーを止めます。強い補正が必要な素材では、音質を優先して手動配置や短いclip単位の編集も検討してください。

Arrange

Arrange は clip を配置、移動、分割、複製、trim する画面です。トラック数が多い場合は下方向スクロールを使い、必要なトラックを選択してから Mix へ移動すると、そのトラックを中心に調整しやすくなります。

Move Lock
clip の誤移動を防ぎます。編集する時だけ解除してください。
Split / Duplicate
選択した clip を切る、または真下へ複製します。切った部分だけを複製する用途にも使えます。
Pan Editor
通常は OFF です。Pan ボタンを押すと表示され、clip の時間軸に沿ってアンカーポイントで左右位置を編集できます。
5x Pan View
Pan 編集時だけ波形を大きく表示できます。指で細かく触るための補助表示です。

Repair Visual / Spectral Editor Pro Lite

Repair は、AI stem に残るクリック、歯擦音、金属的な高域、低域のにじみなどを、範囲指定して軽く補正するための画面です。

機能役割注意
De-Chirp細い高域の鳴きやチリつきを抑えます。強くしすぎると艶も減ります。
De-Harsh耳に刺さる 2kHz から 8kHz 付近を軽く整理します。Vocal の輪郭まで削らないようにします。
De-Click短いクリックやプチ音をなめらかにします。広い範囲へかけるより、問題箇所だけに使います。
Low-End Tighten Lite低域の左右ブレやにじみを抑えます。Bass の芯を削りすぎないようにします。
Removed-only / Delta取り除いた成分だけを確認します。安全のため音量を下げて再生します。

Repair の候補は、FIX するまでは編集候補です。FIX したものだけが export report に反映状態として表示されます。

AIMIX / Unmask Matrix

AIMIX は、音を派手にするためだけの機能ではありません。stem 同士の帯域の重なり、Vocal の見え方、Bass と Kick の場所、Reference との差分を見て、必要な補正を提案します。

  • AIMIX Standard: 最初に使う標準設定です。Balancedを基準に、安全な音量、EQ、Role、Artifact補正を提案します。
  • Run Reference Finish: AIMIXをFIXした後、解析済みReferenceへ音量、密度、帯域を安全に近づけます。
  • A/B: 加工前後を確認します。良くなった時だけ FIX します。
  • Reference Delta: Reference と現在の mix の差を、上限付きで提案へ変換します。
  • Unmask Matrix: Vocal や主旋律を邪魔している帯域だけを軽く ducking します。全帯域を一括で下げる処理ではありません。
  • exportStatus: applied は書き出し反映済み、bypassed は無効または未 FIX、not-wired は保存済みだが現在の export 経路に未接続という意味です。
AIMIX は提案型です。強い補正より、stem の透明感を残す方向を優先してください。

Spatial

Spatial は音像の整理に使います。低域や主役を広げるのではなく、伴奏や装飾音を少し左右や奥へ逃がす考え方です。

  • Spatial Auto: 標準で使用します。AIMIX後のEQを変えず、固定Track Panを安全に設計します。
  • Lead Vocal、Bass、Kick は基本的に中央を保護します。
  • Guitar、Synth、Keys、FX は必要に応じて軽く左右へ配置します。
  • 120Hz 以下を広げる処理は原則避けます。
  • Reference より Side が広すぎる場合、高域 Side を抑えることがあります。

Mastering / Magic Polish / Master Polish 2

Mastering は最終段です。AIMIX と Spatial でバランスを整えた後、音圧、ピーク、低域、艶、ざらつきを確認します。

Dark Gloss
AIMIX Glowの標準プリセットです。Vocalを手掛かりに、刺さりを増やさず控えめな艶と明瞭感を補います。
Light Master
現在のmixを仕上げる標準の簡易マスタリングです。強い音圧化より、バランス、余白、True Peakの安全性を優先します。
Render Processed Master
Dark GlossとLight Masterを現在のmixへ適用し、Original / ProcessedのA/B用音声を準備します。
Export Processed WAV
簡易マスタリング済みのWAVを書き出します。未レンダー時はPolish & Export Processed WAVとして一括処理できます。
Master Polish 2
Reference Delta と Target Profile を使い、低域、安全ピーク、ざらつき、軽い艶をまとめて扱います。
Estimated / Approximate
ブラウザ内での軽量推定です。実測 LUFS メーターの完全代替ではありませんが、A/B と安全確認には有効です。
通常の選択: AIMIX GlowはDark Gloss、Mastering ModeはLight Masterを選びます。Reference Catch-Up、Loudness Only、Loud Releaseは任意の上級設定です。
AI 音源は高域を足すほど良くなるとは限りません。10kHz 以上を増やす前に、500Hz から 5kHz のこもりや Vocal の輪郭を確認してください。
Export truth: Master Polish 2 / Final Repair Modules are shown as applied only when that stage is actually connected to the current export audio. If the report says not-wired, the setting is saved but that stage is not printed into the WAV.

Export Report の読み方

Files 画面の Last Export Report では、書き出しにどの処理が反映されたかを確認できます。

ファイル名: Master WAVはReference名を基準に曲名_sw_master.wavとなり、2回目以降は曲名_sw_master_02.wav、_03.wavと自動採番されます。
表示意味
AppliedFIX 済み、または有効な処理として書き出しに反映されています。
Bypassed無効、未 FIX、または今回の export 対象外です。
Not wired設定や状態は保存されていますが、現在の export 経路には未接続です。警告として扱ってください。
Warnings安全上の注意、未接続、近似値、推定値などの補足です。

Copy または JSON で report を保存しておくと、書き出し結果の確認や不具合調査に使えます。

Performance / Mobile Safety

  • 重い解析や export は chunk に分け、progress と cancel を表示します。
  • iPhone Safari/PWA では、長時間 main thread を止めないことを優先します。
  • Project / .swtd には巨大な解析行列や raw PCM cache を保存しません。
  • mobile では 0.5 から 1.0 秒程度の audio chunk を目安にします。
  • full-band widen、強い high exciter、過剰な limiter は初期設定では使いません。
音が悪くなる典型例: Reference トラックを実音として混ぜる、Limiter 後に master gain を上げる、複数トラックへ高域サチュレーションを重ねる、Vocal の De-Esser を強くしすぎる、低域を stereo に広げる。
Sweet DAW はブラウザ内で動作するローカル処理中心の DAW です。元ファイルを直接上書きしません。
