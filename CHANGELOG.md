# Changelog

All notable public releases of Sweet DAW will be documented here.

The project is currently pre-1.0. Until the public API and project format stabilize, minor releases may include breaking changes when they are clearly documented.

## [0.1.0] - 2026-09-16

### Initial open-source release

- Published Sweet DAW under the MIT License from a reviewed source snapshot.
- Established a clean public Git history without importing private development history or backup/build artifacts.
- Added mobile-first arrange, mix, repair, mastering, and project-export workflows.
- Included browser-local BPM Lock material rendering.
- Included AIMIX, Mix Doctor, reference-analysis, spatial, repair, and mastering modules.
- Included project-owned/browser-native DSP plug-ins and export processing.
- Added automated typecheck, test, production-build, and AIMIX self-test verification.
- Added contribution, security, third-party licensing, and release-provenance documentation.

### Release posture

The v0.1.0 source snapshot intentionally excludes user audio, commercial samples, external IR libraries, model weights, native plug-in binaries, third-party WASM DSP binaries, credentials, and private development history.
